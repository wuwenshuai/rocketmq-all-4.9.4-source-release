# Day0：环境与怎么用（约 1 小时，第一次必做）

学源码之前，先保证你能稳定启动、发消息、看日志。后面每天都依赖这一步。

---

## 1. IDEA 里启动 NameServer

打开类：

`namesrv/src/main/java/org/apache/rocketmq/namesrv/NamesrvStartup.java`

方法：`main(String[] args)`

### Run Configuration

| 项 | 值 |
|----|----|
| Main class | `org.apache.rocketmq.namesrv.NamesrvStartup` |
| Module | `rocketmq-namesrv` |
| VM options | 见下 |

```text
-Drocketmq.home.dir=/Users/wl/Desktop/code/rocketmq-all-4.9.4-source-release/distribution/target/rocketmq-4.9.4/rocketmq-4.9.4
-Xms512m -Xmx512m
```

成功标志：

```text
The Name Server boot success. serializeType=JSON
```

---

## 2. IDEA 里启动 Broker

打开类：

`broker/src/main/java/org/apache/rocketmq/broker/BrokerStartup.java`

方法：`main(String[] args)`

| 项 | 值 |
|----|----|
| Main class | `org.apache.rocketmq.broker.BrokerStartup` |
| Module | `rocketmq-broker` |
| VM options | 同上 `rocketmq.home.dir` |
| Program arguments | 见下 |

```text
-n 127.0.0.1:9876 -c /Users/wl/Desktop/code/rocketmq-all-4.9.4-source-release/distribution/target/rocketmq-4.9.4/rocketmq-4.9.4/conf/broker-local.conf
```

成功标志（注意必须是 127.0.0.1，不是网卡 IP）：

```text
The broker[broker-a, 127.0.0.1:10911] boot success. serializeType=JSON and name server is 127.0.0.1:9876
```

如果提示 `Lock failed, MQ already started`：

```bash
rm -f ~/store/lock
```

## 3. 用命令确认集群活着

```bash
export JAVA_HOME=/Library/Java/JavaVirtualMachines/jdk-1.8.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
cd /Users/wl/Desktop/code/rocketmq-all-4.9.4-source-release/distribution/target/rocketmq-4.9.4/rocketmq-4.9.4

sh bin/mqadmin clusterList -n 127.0.0.1:9876
```

你应该看到 `broker-a` 和 `127.0.0.1:10911`。

## 4. 改一个 Example 方便本地跑

打开：

`example/src/main/java/org/apache/rocketmq/example/quickstart/Producer.java`

把这行取消注释 / 改成：

```java
producer.setNamesrvAddr("127.0.0.1:9876");
```

消费者同理：

`example/src/main/java/org/apache/rocketmq/example/quickstart/Consumer.java`

也加上：

```java
consumer.setNamesrvAddr("127.0.0.1:9876");
```

先 Run Consumer，再 Run Producer。控制台能看到 `Hello RocketMQ` 就说明收发通了。

## 5. 日志和磁盘文件在哪

```bash
# 运行日志
ls ~/logs/rocketmqlogs/
tail -f ~/logs/rocketmqlogs/namesrv.log
tail -f ~/logs/rocketmqlogs/broker.log
tail -f ~/logs/rocketmqlogs/store.log

# 消息落盘位置
ls ~/store/
ls ~/store/commitlog/
ls ~/store/consumequeue/
```

记住：

- `commitlog/`：消息本体
- `consumequeue/`：按 Topic 分的索引
- `config/`：Topic、消费位点等配置

## 6. 每天学习时的标准动作

1. 停掉没用的旧进程（避免端口占用）
2. Debug 启 NameServer
3. Debug 启 Broker
4. 在文档指定的方法打断点
5. Debug 跑 Example
6. 看断点停在哪，对照文档解释
