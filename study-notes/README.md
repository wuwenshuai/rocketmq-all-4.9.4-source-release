# RocketMQ 4.9.4 源码学习计划（面试向）

这套文档是给你本地这份 **RocketMQ 4.9.4** 源码准备的。目标不是把每个类都读完，而是：

1. 能讲清架构和关键设计
2. 能在 IDEA 里顺着断点把一条消息走通
3. 能回答常见面试题，并能联系生产排障

每天按 **3～4 小时**设计，大约 **12 天**。按顺序学效果最好，但某一天太难可以先跳到实践部分，再回头看源码。

---

## 怎么用这套文档

1. 每天只打开当天的 `day-xx-xxx.md`
2. 先看「今日目标」和「关联面试题」
3. 按「本地操作」把 NameServer / Broker / Example 跑起来
4. 再按文档里的 **类名 + 方法名** 打断点
5. 最后用「面试怎么答」自己对着镜子讲一遍（不超过 2 分钟）

## 一张总图（先记住这个）

```text
Producer ──查路由──▶ NameServer(只存路由，不存消息)
   │                      ▲
   │发消息                │定时注册(约30s)
   ▼                      │
Broker ──写──▶ CommitLog(消息本体，所有Topic混写)
   │
   └──▶ ConsumeQueue(按Topic+队列的索引) ──▶ Consumer 拉消息
```

一句话：

- **NameServer**：电话簿
- **Broker**：仓库
- **CommitLog**：货物本身
- **ConsumeQueue**：货架标签
- **客户端**：自己去查电话簿，再直连仓库
